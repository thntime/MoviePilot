# 目标

修复网盘账号控制台部署后暴露的 4 个界面问题：新增/编辑账号时登录方式在浏览器中不可见、平台一级菜单默认折叠、详情操作按钮位置与顺序不符合预期、已保存凭证占用高度过高。

# 范围

## 目录结构

### 新建

无

### 修改

- `MoviePilot-Frontend/src/components/dialog/NetdiskAccountDialog.vue` — 移除包裹登录方式区块的无指令 `<template>`（Vue 3.5 会把它编译成原生 `<template>` 元素，浏览器中内容不可见），让标签与表单直接作为表单子节点渲染。
- `MoviePilot-Frontend/src/components/setting/NetdiskAccountList.vue` — 平台一级菜单默认全部展开，仍可手动折叠。
- `MoviePilot-Frontend/src/views/setting/AccountSettingNetdisk.vue` — 移动端平台分组默认全部展开，与桌面一致。
- `MoviePilot-Frontend/src/components/setting/NetdiskAccountDetail.vue` — 操作按钮移到「平台 / 状态 / 主账号」标签行右侧（存储空间上方），顺序改为：检测连通性、刷新令牌、设为主账号、编辑账号、删除账号；已保存凭证改为单行只读输入框并保留复制。
- `MoviePilot-Frontend/src/locales/zh-CN.ts`、`zh-TW.ts`、`en-US.ts` — 如需新增或调整文案，三份同步。

### 删除

无

### 明确不建

- 不改后端接口、数据模型与调度任务。
- 不改动其他设置页、网盘文件浏览、登录后端逻辑。
- 不引入新的运行时依赖。

# 非目标

- 不重新设计控制台整体布局（平台菜单、70/30 详情、内嵌文件浏览保持现状）。
- 不调整扫码登录后端会话与轮询逻辑。
- 不改变账号增删改的业务语义。

# 验收示例

- A1 登录方式可见：新增账号与编辑账号对话框在浏览器中都能看到登录方式标签（粘贴 Cookie、CookieCloud 导入、平台支持时的账号密码/短信、网页登录），切换标签后对应表单可见并可提交。
- A2 平台默认展开：桌面与移动端的网盘平台一级菜单首次进入时全部展开，显示该平台下账号；用户仍可逐个折叠。
- A3 操作按钮位置：账号详情中「平台 / 状态 / 主账号」标签行右侧依次显示 检测连通性、刷新令牌、设为主账号、编辑账号、删除账号；账号信息与存储空间区域不再包含这些按钮。
- A4 凭据单行展示：已保存凭证以单行只读输入框展示（不换行、不撑高详情），保留一键复制。

# 关键决定

- 登录方式不可见的根因：`NetdiskAccountDialog.vue` 用无指令的 `<template>` 包裹 `VTabs`/`VWindow`，Vue 3.5 将其编译为原生 `<template>` 元素，内容在浏览器中不渲染；修复方式是移除该包裹层，而不是改登录方式数据或后端。
- 本次只改前端 `MoviePilot-Frontend`，后端与已归档的 `netdisk-account-console` 能力行为不变。
- 平台菜单默认展开，但保留用户手动折叠能力，不做持久化。
- 操作按钮与标签行同一行，窄屏自动换行；顺序固定为 检测连通性 → 刷新令牌 → 设为主账号 → 编辑账号 → 删除账号。
- 凭据使用单行只读输入框（可横向滚动查看），复制按钮放在输入框尾部。
